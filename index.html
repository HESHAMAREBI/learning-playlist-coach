Learning Playlist Coach

Track. Learn. Resume. Ask AI.

Microsoft Edge Extension for YouTube Learning Playlists

Features

✅ Playlist Tracking

Track completed videos and monitor learning progress.

✅ Resume Learning

Return to the last watched video automatically.

✅ Ask AI Coach

Generate contextual prompts from the current video.

✅ Backup & Restore

Export and import progress across devices.

Privacy

This extension stores learning data locally on the user's device. No personal information is collected.
