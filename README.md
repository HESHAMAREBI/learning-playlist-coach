# Learning Playlist Coach

Learning Playlist Coach is a Microsoft Edge extension designed to help learners track YouTube playlist progress, resume where they stopped, and interact with AI learning assistants.

## Features

✅ Playlist progress tracking

✅ Resume from last watched video

✅ AI Coach integration

✅ Screenshot capture from videos

✅ Backup and Restore

✅ Study plan support

✅ Progress statistics

## How it Works

1. Open a YouTube playlist.
2. Track completed videos.
3. Save progress automatically.
4. Ask AI Coach about the current video.
5. Export and import backups when needed.
