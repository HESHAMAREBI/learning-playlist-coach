# Privacy Policy

Last Updated: September 2026

Learning Playlist Coach respects user privacy.

## Data Collection

This extension does not collect personal information.

This extension does not transmit user data to external servers.

## Local Storage

The extension stores the following information locally on the user's device:

- Playlist progress
- Completed videos
- Backup data
- User settings
- AI Coach settings

## AI Coach

When the user chooses to open an AI assistant, the extension only opens the configured URL.

No information is transmitted to the extension developer.

## Third-Party Services

Learning Playlist Coach does not operate any external servers.
